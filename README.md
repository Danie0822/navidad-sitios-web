# Villa Navidad

Sitio estático navideño en HTML, CSS y JavaScript, con Tailwind compilado por CLI (sin CDN).

## Páginas

- **Inicio** (`index.html`) — portada y cuenta regresiva a Navidad
- **Tarjetas** (`tarjetas.html`) — crear y descargar una tarjeta PNG
- **Juegos** (`juegos.html`) — memoria y regalos escondidos
- **Participantes** (`participantes.html`) — créditos y multimedia

## Cómo correrlo

```bash
npm install
npm run preview:pages
```

Abrí http://localhost:4173/navidad-sitios-web/

Para regenerar el CSS de Tailwind:

```bash
npm run css:build
```
